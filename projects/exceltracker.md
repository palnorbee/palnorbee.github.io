<h1 style="color:#9300ff">Excel HAACP tracker in AppSheet</h1>
<h3>I started this project as a solution for a problem we faced at my former workplace.We kept track with the HAACP on a simple Excel spreadsheet, which had to be created weekly. The biggest issue was how inconvenient it was to type and fill out the cells daily. I didn't have much experience with coding, and I was looking for something like a frame that could handle those sheets as input. That's when I found AppSheet, which is simple and brilliant for smaller projects, without starting to code from zero. Well, it still wasn't easy to begin with; I had the vision but had to think it through.<h3>
<h3> What was done is a simple, easy-to-read app with buttons and sliders. The data is both registered in the app and in your spreadsheet. Unfortunately, management turned down the idea thus i stopped finishing it.The overall missing things:
<h3></h3><ul><li>Fixing auto. date/time</li><li>Automatic sheet creation from a template</li></ul><h3>
<h3>Both of those can be easily implemented, though the automation is a paid service from AppSheet.<h3>
